# EdgeLog

Persönliches Day-Trading-Journal mit Live-Trades, Backtesting und Auswertung.

## Funktionen
- Live- und Backtest-Trades getrennt
- Winrate, P&L, R-Multiple und Profit Factor
- Analyse nach Setup und Session
- JSON-Backup und CSV-Export
- Offline-fähige PWA
- Daten werden lokal im Browser per IndexedDB gespeichert
